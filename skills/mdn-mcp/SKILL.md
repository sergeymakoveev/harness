# MDN MCP

## Назначение

MDN MCP даёт агенту актуальный доступ к официальной документации MDN Web Docs:
поиску, полным страницам документации и данным совместимости браузеров (BCD).
Используй его для вопросов о возможностях веб-платформы: HTML-элементах,
CSS-свойствах, JavaScript и Web API. Для документации библиотек, фреймворков,
SDK и облачных сервисов выбери специализированный источник документации.

Сервер экспериментальный. Запросы могут сохраняться Mozilla; не передавай в них
секреты или персональные данные. Если клиент позволяет задать HTTP-заголовок,
для отказа от first-party аналитики укажи
`X-Moz-1st-Party-Data-Opt-Out: 1`.

Уточни у MCP-клиента фактические имена доступных инструментов:
клиент может добавить префикс имени сервера, например `mdn_search` вместо
`search`.

## Инструменты и порядок работы

1. `search`
   - Вход: `query` — короткие технические ключевые слова, например `fetch`,
     `array methods` или `CSS flexbox`.
   - Назначение: находит релевантные страницы MDN, возвращает краткие описания,
     `path` страниц и иногда `compat-key`/`compat-keys`.
   - Всегда начинай с него, когда путь страницы или BCD-ключ неизвестен. Не
     добавляй в поисковую фразу слова «совместимость браузеров» — ищи имя
     возможности.

2. `get-doc`
   - Вход: `path` — путь или полный URL страницы MDN, например
     `/en-US/docs/Web/API/Headers`.
   - Назначение: возвращает полную документацию в Markdown: описание, сигнатуры,
     примеры, спецификации и связанные сведения.
   - Передавай `path` из результата `search`. Инструмент принимает только URL
     `developer.mozilla.org` и пути документации.

3. `get-compat`
   - Вход: `key` — BCD-ключ, например `api.fetch`.
   - Назначение: возвращает JSON с поддержкой возможности в настольных и
     мобильных версиях Chrome, Firefox, Safari, Edge и других браузеров.
   - Бери ключ исключительно из `compat-key` или `compat-keys`, выданных
     `search` либо `get-doc`; не подбирай его вручную. Интерпретируй JSON для
     вопроса пользователя и называй затронутые браузеры и версии.

Обычный маршрут: `search` → `get-doc` для подробного ответа; при вопросе о
поддержке — `search` → `get-compat` (при необходимости также `get-doc`).
Ссылайся на соответствующую страницу MDN из результата поиска или документации.
